# Первая проверка RPC

Запуск: `cargo run --bin check_rpc -- https://RPC_HOST EXPECTED_CHAIN_ID`.
Нужен публичный CometBFT RPC base URL без секретов; `.env` команда не читает.
Команда делает GET `/status` с таймаутом 10 секунд, без повторов и редиректов.
Успех: ожидаемый chain ID, `catching_up=false` и положительная высота блока.
Ошибка HTTP/JSON/RPC, другая сеть или несинхронизированная нода дают ненулевой exit code.
Проверка не доказывает свежесть блока, доступность истории или наличие Factory.

На 2026-10-14 адрес Factory и endpoint не подтверждены; живой замер не выполнен.
Следом: записать публичные параметры развёртывания и проверить Factory ContractInfo.
